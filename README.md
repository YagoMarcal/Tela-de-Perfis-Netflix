# 🎬 Tela de Perfis Netflix

Recriação da tela de escolha de perfil da Netflix utilizando apenas **HTML** e **CSS**.

##  Objetivo

Praticar a construção de interfaces com HTML e CSS, reproduzindo fielmente o layout, o alinhamento e os efeitos visuais da tela "Quem está assistindo?" da Netflix.

##  Funcionalidades

- Exibição de 4 perfis com avatar e nome
- Layout centralizado e responsivo [confirme se é responsivo]
- Efeito de destaque ao passar o mouse sobre cada perfil (hover) [confirme]
- Fundo escuro seguindo a identidade visual da plataforma

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

##  Estrutura do projeto

```
Tela-de-Perfis-Netflix/
```

##  Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/YagoMarcal/Tela-de-Perfis-Netflix.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd Tela-de-Perfis-Netflix
   ```
3. Abra o arquivo “index.html” no seu navegador.

##  Aprendizados

- Uso de Flexbox para alinhamento de elementos
- Organização de HTML semântico e CSS separado
- Estilização de estados com `:hover`
